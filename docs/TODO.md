## General Manager

Daily tips for each team, generated on every ESPN fetch (the scheduled runs at 7 AM and 3 PM) and shown on the website to
that team's logged-in member.

- **Strengths and weaknesses:** which of the 9 categories the team wins and loses, from its season
  and recent weekly ranks, and how close it is to the teams around it in each one.
- **Suggested moves**, each with a short reason tied to those strengths and weaknesses:
  - **Start / sit:** start one player instead of another (games this week, injuries, category fit).
  - **Add / drop:** pick up a free agent who helps a weak category, and who to drop for them.
  - **Trade:** a fair trade with a specific team whose strengths match this team's weaknesses
    (e.g. give assists for rebounds), without checking every other team by hand.
- Generated by Claude in the scheduled run (`update.yml` on GitHub Actions), so no API key reaches
  the browser. `ANTHROPIC_API_KEY` is a GitHub repository secret, like the ESPN cookies.
- Needs more ESPN data than today: free agents and each team's schedule of games this week.
- Cost: one Claude call per team per run (2 runs a day). Set a monthly limit in the Anthropic Console
  and use the cheapest model that gives good tips.
- Anything on GitHub Pages is public (the login screen doesn't protect files), so tips that should
  stay private to each team must be stored with the Worker (e.g. the run uploads them to Workers KV)
  and served only to the logged-in team.

## Win chance

Each matchup's chance to win this week, as a percentage for both teams (e.g. 62% / 38%), shown on
the Weekly page and updated on every run.

- Start from the 9 category totals so far this week, then estimate the rest of the week from each
  player's per-game averages and the games they have left (a simulation run many times, counting
  how often each team wins the most categories).
- Needs the same extra ESPN data as the General Manager: each team's schedule of games this week.
- Before the week starts it's based on averages only; on the last day it's close to 0% or 100%.

## Today's game

On the Teams page, small gray text next to each player's name showing whether they play today and
against whom, like ESPN's roster: the opponent on one line and the tip-off time under it
(`ORL` / `10:00 PM`, `@POR` / `11:00 PM`), or `-` for no game.

- Opponent with `@` for away games, and the tip-off time in New York time.
- Needs the NBA schedule from ESPN (the same game schedule the General Manager and Win chance use).
- Data is from the latest run (7 AM / 3 PM), so it shows the scheduled time, not live scores.
